CURRENT SYSTEM:
- User can:
  1. Enter AI description → generate structured JSON
  2. View/edit JSON
  3. Analyze JSON → get categorized outcomes
  4. See checkboxes per bullet point
  5. Export selected outcomes

GOAL:
Introduce a mode toggle that changes how the workflow behaves, while keeping all current features intact.

----------------------------------
1. ADD MODE TOGGLE UI
----------------------------------

Add a toggle at the top of the page:

Label:
"Mode: [ Normal | Expert ]"

- Default mode: Normal
- Can be a switch or radio buttons
- Store selected mode in a variable (e.g., currentMode)

----------------------------------

----------------------------------

In Normal Mode:

- User only sees:
  - AI description input box
  - One button: "Generate & Analyze"

- When clicked:
  1. Send description → /generate-json
  2. Automatically take returned JSON
  3. Immediately send it → /analyze
  4. Display ONLY the final analysis results

  - JSON textarea
  - "Analyze Potential Outcomes" button

- Keep:
  - Loading messages for both steps
  - Checkbox per bullet point
  - Export selected outcomes button
  - Popup modal

----------------------------------
3. EXPERT MODE BEHAVIOR
----------------------------------

In Expert Mode:

- Show full existing interface:
  - AI description input
  - "Generate Structured JSON" button
  - JSON textarea (editable)
  - "Analyze Potential Outcomes" button

- Behavior:
  1. User generates JSON manually
  2. JSON is inserted into textarea
  3. User can edit JSON
  4. User clicks "Analyze Potential Outcomes"
  5. Analysis is displayed

- ALSO:
  After generating JSON, automatically run analysis once (optional but preferred for speed)
