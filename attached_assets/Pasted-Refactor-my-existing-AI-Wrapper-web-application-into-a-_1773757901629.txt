  - Export selected items popup

- Ensure API key is NOT exposed in frontend

4. PROJECT STRUCTURE:
Organize files like:

/project
  ├── server.js
  ├── package.json
  ├── .env
  └── /public
        └── index.html

5. CONNECTION:
